## 第一步：绑弹性公网 IP（只有控制台能做，2 分钟）
1. 打开 https://vpc.console.aliyun.com/eip （地域选 **华东1 杭州**）
2. 创建弹性公网IP：计费方式「按使用流量」，带宽峰值 5 Mbps（够演示；流量 0.8 元/GB）
3. 创建后 → 绑定资源 → 实例 → 选 i-bp19e9sqxj9877d1a4re
4. 支付时可用账户里 299 元代金券（EIP 是原价产品，券可抵）

## 第二步：安全组放行端口（控制台）
实例 → 安全组 → 配置规则 → 入方向 → 手动添加：
- 22/22 授权对象 0.0.0.0/0（SSH）
- 80/80 授权对象 0.0.0.0/0（网页）
- 3000/3000 授权对象 0.0.0.0/0（Node 直连调试用）

## 第三步：SSH 登录并跑初始化脚本
```bash
ssh root@<EIP>          # 密码在控制台「重置实例密码」里设置
```
把 部署/server-bootstrap.sh 内容整段粘贴执行（先填好 .env 里的两个 key）。
脚本做的事：装 Node20+pnpm+pm2+nginx → clone Gitee 仓 → pnpm build → pm2 常驻 → nginx 80 反代 3000 → ufw 放行。
