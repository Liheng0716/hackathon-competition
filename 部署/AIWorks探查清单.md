# AI Works 部署可用性探查（零花费主线）

## 一、已核实（官方新闻稿原文，2026-09-05 网易科技转知乎消息）
1. AI Works 2026 年 6 月上线，是知乎的 AI 项目发布/展示/体验平台，支持 AI 工具、Skill、智能体、应用、游戏 等类型
2. 2026-09-05 更新「应用一键部署」：开发者上传完整项目工程包 → 平台云端构建和部署，把部署纳入发布流程
3. 同时提供「多层安全检测 + 发布审核机制」
4. 平台累计 2600+ 项目，说明常规项目能正常过审上线

## 二、待现场确认（必须看到创建项目页的表单才算数）
1. 是否支持 Node 服务端（我们用了 app/api/* 路由 + SSR，纯静态托管跑不起来）
2. 构建方式：是否读 package.json 自动 install + build，能否指定构建/启动命令
3. 环境变量：能否注入 ZHIPU_KEY / DASHSCOPE_KEY（不能注入则模型调用要在浏览器端，等于泄 key，方案要改）
4. Node 版本（要求 ≥18，最好 20）
5. 部署后链接：是否公网、游客免登录、有无自定义域名
6. 审核时长与免费额度（零费用？调用次数/带宽限制？）
7. 工程包限制：zip 大小、是否排除 node_modules

## 三、零花费备选（不买 EIP、不买域名）
**Cloudflare Tunnel（cloudflared）跑在已买的 0 元 ECS 上**
1. ECS 已购（2核4G 杭州，0 元，到期 12-02），当前无公网 IP——不绑 EIP（要钱）
2. ECS 上装 cloudflared，执行 cloudflared tunnel --url http://localhost:3000，直接得到 https://xxx.trycloudflare.com 公网链接
3. 优点：0 元、真 HTTPS、不需公网 IP、不需备案、不需域名
4. 风险：trycloudflare 国内速度一般、偶尔不稳；正式发布优先 AI Works，隧道作内测/兜底

## 四、执行顺序（零花费）
1. 摸 AI Works 创建项目页 → 确认第二节 7 项 → 通过则走 AI Works 主线（公开、稳定、有知乎流量）
2. 若 AI Works 不支持 Node 服务端或不能注入环境变量 → 立即切 cloudflared 隧道（ECS 已就位，只需 SSH）
3. 两条都不花钱；EIP / 域名 / 服务器续费全部不做
